# YouTube ShortStopper

YouTube Shorts を**見れなくはしない**。惰性で次に流れていく経路だけを塞ぐ Chrome 拡張。

- **ループしない** — 最後まで再生したら、そこで止まる
- **スクロールで次に行かない** — ホイール・スワイプ・上下キーでの移動を止める
- **自動送りしない** — 再生が終わっても勝手に次の動画に移らない
- **次に進む道は残す** — 止まったところに出るカードから、待ち時間のあと 1 クリックで進める

触るのは `www.youtube.com/shorts/` のページだけ。通常の動画・再生リスト・ライブ・
**YouTube Music（`music.youtube.com`）** には一切手を入れないので、ラジオ代わりに
流しながらの作業はそのまま続けられる。

## 入れかた

1. このリポジトリをクローン（または ZIP をダウンロードして展開）する

   ```
   git clone https://github.com/tanmen/youtube-shortstopper.git
   ```

2. Chrome で `chrome://extensions` を開き、右上の **デベロッパー モード** をオンにする
3. **パッケージ化されていない拡張機能を読み込む** を押して、`manifest.json` がある階層の
   フォルダを選ぶ（`icons` `scripts` `src` が並んで見えていれば正しい。`src` の中まで
   入っていると「マニフェスト ファイルが見つからない」で失敗する）
4. YouTube のタブを開いていたら再読み込みする（content script は読み込み済みのタブには入らない）

更新したときは `chrome://extensions` の再読み込みボタンを押してから、YouTube のタブも再読み込みする。

## 使いかた

Shorts を開くと、画面の**右上**に**今日見た本数**が小さく出る（中央だと動画に被るため）。
最後まで再生すると再生が止まり、カードが出る:

| ボタン           | 動き                                                       |
| ---------------- | ---------------------------------------------------------- |
| もう一度見る     | 頭から再生し直す                                           |
| 次へ進む         | YouTube 標準の「次の動画」を押す。既定では 5 秒たつまで押せない |
| YouTube のホームに戻る | Shorts から抜ける                                    |

スクロールやキーで進もうとしたときは画面が動かず、代わりに**画面の隅に大きく**
「スクロール制限中」のポップアップが出る。同じ動画で繰り返すと「この動画で N 回目」が付く。

既定の位置は**右下**。Shorts の視線は動画の中央〜右（いいね・コメントの列）にあり、
右上は YouTube 自身のヘッダー（アカウント・通知）と重なるため。設定で右上にも寄せられる。

### どうしても見たいとき

拡張アイコンのポップアップから **15 分だけ解除** できる。時間が来ると自動で元に戻るので、
「気になって切ったまま」にならない。解除中はバッジが色つきになる。

### 設定

ポップアップの「詳しい設定」から:

- スクロールでの移動を止める（オン / オフ）
- ループと自動送りを止める（オン / オフ）
- 「制限中」ポップアップの位置（右下 / 右上）
- 「次へ進む」が押せるまでの待ち時間（0〜30 秒）
- 何本ごとに声をかけるか（0 で出さない）

設定は `chrome.storage.sync`、本数と一時解除は `chrome.storage.local` に入る。
外部に何も送らないし、閲覧履歴も残さない（今日の本数という 1 つの整数だけ）。

## 中身

| ファイル           | 役割                                                       |
| ------------------ | ---------------------------------------------------------- |
| `manifest.json`    | MV3。権限は `storage` のみ                                 |
| `src/content.js`   | 本体。入力の遮断と再生の監視                               |
| `src/content.css`  | Shorts に重ねるバッジ・制限中ポップアップ・停止カード      |
| `src/popup.*`      | 本数の表示と 15 分の一時解除                               |
| `src/options.*`    | 詳しい設定                                                 |
| `scripts/check.mjs`| 読み込む前の整合性検査（`node scripts/check.mjs`）         |
| `scripts/sync-parent.mjs` | Chrome が読む本体の checkout を origin/main に進めて検査する |
| `scripts/make-icons.py` | アイコンの生成（`python scripts/make-icons.py`）      |

### worktree で直したとき

Chrome が読み込んでいるのは**clone した本体のフォルダ**で、`git worktree` で切った別の作業ツリー
（`.claude/worktrees/` の下など）で直した分は、マージして本体を進めるまで Chrome に出ない。
マージしたら、どの worktree からでも次を叩くと本体が origin/main に進み、本体側で `check.mjs` が走る。

```
node scripts/sync-parent.mjs
```

本体が `main` 以外にいる・追跡ファイルに変更がある・fast-forward で済まないときは、本体に触らず理由だけ出す。
進めたあとは `chrome://extensions` の再読み込みと YouTube のタブの再読み込みが要る。

### 止め方の理屈

ループを止める要は **`video.loop` を外すことではない**。2026-09-01 に実際の Shorts ページで
測ったところ、デスクトップの player は再生中も `loop` が `false` のままで、終端に達したあと
内部で巻き戻していた。属性を外すだけでは止まらない。

そこで本体は **終端の 0.15 秒手前で `pause()` する**。終端に届かなければ、ループも自動送りも
`ended` も起こらない。同じページで、0.1 秒手前で止めたあと 2.5 秒待っても
再生は再開せず、URL も変わらないことを確認した。

取りこぼしたときのために 2 つ受け皿を置いてある。

- `document` の capture 段で `ended` を掴んで握りつぶす（`ended` はバブルしないが
  capture 段には届き、`video` 自身に付いたハンドラより先に走ることを実測で確認した）
- 終端付近から `currentTime` が 0 付近に飛んだら、内部ループとみなして止める

「いま見ている動画」の特定に `ytd-reel-video-renderer[is-active]` のような属性は使っていない
（実測したところ、その属性は付いていなかった）。画面の中央に一番近い `<video>` を選ぶので、
YouTube 側のマークアップが変わっても壊れにくい。
